\# TECH STACK



\## FRONTEND

\- \*\*HTML5 \& CSS3:\*\* Pure, raw styling (No Tailwind, No Bootstrap).

\- \*\*Vanilla JavaScript:\*\* For DOM manipulation and Socket.io client handling.

\- \*\*CryptoJS:\*\* For client-side AES-256 encryption and decryption.



\## BACKEND

\- \*\*Node.js:\*\* Runtime environment.

\- \*\*Express.js:\*\* For static file serving and basic authentication routing.

\- \*\*Socket.io:\*\* For real-time, bi-directional communication.



\## DATABASE

\- \*\*SQLite:\*\* Lightweight, server-side storage. Only stores user credentials and ciphertext messages.
