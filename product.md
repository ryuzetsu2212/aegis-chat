\# PRODUCT DEFINITION: AEGISCHAT (MANUAL E2EE)



\## CORE CONCEPT

A highly secure, stealth-focused real-time chat application where encryption is fully manual and controlled by the user. It functions similar to PGP communication but streamlined for a chat interface.



\## KEY FEATURES

1\. \*\*Account System:\*\* Simple user login/registration.

2\. \*\*Manual Encryption:\*\* Users type a message, input a shared Secret Key, and manually click "Encrypt" to transform the text into Base64 AES-256 ciphertext before sending.

3\. \*\*Manual Decryption:\*\* Received messages display as raw ciphertext. Users must click "Decrypt" and input the correct Secret Key to read the message.

4\. \*\*Zero-Knowledge Server:\*\* The server only routes and stores encrypted strings.
